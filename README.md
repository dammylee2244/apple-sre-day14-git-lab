
# Linux Monitoring Toolkit

## Project Overview

A beginner SRE engineering project designed to
monitor Linux system health and identify potential
operational issues.

## Current Capabilities

- Linux system health monitoring
- Bash automation
- Python log analysis
- Error detection
- Scheduled monitoring

## Technologies

- Linux
- Bash
- Python
- Git
- GitHub
## Monitoring Capabilities

### Disk Monitoring
Checks available and used disk capacity
and identifies potentially critical usage.

### Memory Monitoring
Reports total memory, available memory,
and current utilization.

## Operational Considerations

- Monitor resource utilization regularly.
- Investigate abnormal resource consumption.
- Review logs when monitoring checks fail.
- Use thresholds to identify potential incidents.
## Project Objective

Develop practical skills in Linux administration,
monitoring, automation, troubleshooting and
reliability engineering.
