
# Linux Monitoring Toolkit

## Project Overview

A beginner SRE engineering project designed to
monitor Linux system health and identify potential
operational issues.

## Current Capabilities

- Linux system health monitoring
- Bash automation
- Python log analysis
- Error detection
- Scheduled monitoring

## Technologies

- Linux
- Bash
- Python
- Git
- GitHub

## Project Objective

Develop practical skills in Linux administration,
monitoring, automation, troubleshooting and
reliability engineering.
